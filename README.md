# 108TEA Club — Static Site

A minimal, calm one-page website for 108TEA Club (Berlin).  
Built with plain **HTML/CSS/JS**, no frameworks, easy to host on GitHub Pages.

## Structure
- `index.html` — single-page site with sections:
  - About
  - Tea Menu
  - Ceremonies
  - Learn / Brewing Guide
  - Links & Community
  - Contact
- `styles.css` — minimal, responsive styles
- `script.js` — smooth scroll, year, mobile nav

## How to run (GitHub Pages)
1. Create a new GitHub repo, for example `108tea.club` or any name you like.
2. Upload all files from this folder to the repository root.
3. Enable **Settings → Pages → Deploy from branch** (main) → `/ (root)`.
4. Open the URL shown by GitHub Pages.

## Customization
- Replace Telegram/Instagram/YouTube links in `index.html`.
- Update tea list in the **Tea Menu** section.
- Adjust colors in `styles.css` (CSS variables at the top).
- Add images to `/assets` if needed and reference them in `index.html`.
