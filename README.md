# 108TEA Club — Compact Site

Minimal one‑pager with four sections only: About, Ceremonies, Learn, Contact.  
Plain HTML/CSS/JS — perfect for GitHub Pages.

## Deploy
1) Upload files to a public GitHub repo (root).  
2) Enable Settings → Pages → Deploy from branch (main / root).  
3) Open the Pages URL.

## Customize
- Texts: `index.html`  
- Colors: `styles.css`  
- Links: Instagram / Telegram / @ama108 / Email in `index.html`
